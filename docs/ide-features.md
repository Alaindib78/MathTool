# IDE Features

MathTool combines a script editor, Command Window, Workspace panel, Current Folder browser, Path Manager, plotting backend, debugger, and integrated Help browser.

## Documentation integration

The Help browser is dockable and can be opened from the Help menu, with F1, or from REPL commands such as:

```mathtool
help plot
doc matrices
```
