# Keyboard Shortcuts

| Shortcut | Action |
| --- | --- |
| `F1` | Open Help |
| `Ctrl+F` | Focus search in the Help browser |
| `Ctrl+K` | Quick help search |
| `Ctrl+Return` | Run code |
| `F5` | Continue debugging |
| `F10` | Step while debugging |
| `F9` | Add breakpoint |
| `Ctrl+N` | New file |
| `Ctrl+O` | Open file |
| `Ctrl+S` | Save file |
