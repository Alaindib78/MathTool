# REPL

The Command Window evaluates one command or expression at a time. Use the prompt for calculations, workspace inspection, and help lookup.

```mathtool
>> x = linspace(0, 1, 5)
>> help linspace
>> doc plotting-guide
>> lookfor eigen
```

Use the Up and Down keys to navigate command history.
