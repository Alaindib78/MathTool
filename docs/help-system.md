# doc

`doc` opens the integrated Help browser. Use it for function pages, guides, examples, and IDE topics.

```mathtool
doc plot
doc matrices
doc shortcuts
```

Use [help](topic:help) for console-formatted documentation and [lookfor](topic:lookfor) for keyword search.
